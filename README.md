# Weather Dashboard

A responsive weather dashboard built with Vite and vanilla JavaScript. It uses the free [Open-Meteo](https://open-meteo.com/) geocoding and forecast APIs; no API key is required.

## Features
- Search by city name (starts with a London forecast)
- Optional browser geolocation
- Current conditions, hourly forecast, and 7-day outlook
- Responsive layout, loading/error feedback, and accessible search controls

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Browser geolocation generally requires a secure context (HTTPS or localhost).

## Build

```sh
npm run build
```
