# Hay! One Million! 3D Game

A browser-based 3D incremental game built with Three.js and Vite.

## Features
- Giant 3D hay mound made from 10,000 hay strands
- Click or drag to clear hay around the brush area
- Hay counter uses 100 hay per strand for a 1,000,000 total target
- Gold coins drop when clearing hay
- Upgrades for brush radius, clearing power, and auto-rake
- Hidden silver needle revealed after enough clearing
- Win state when the silver needle is clicked

## Local development
```bash
npm install
npm run dev
```

Then open the URL shown in the terminal.

## Production build
```bash
npm run build
```

## Deploy to GitHub Pages
After building, publish the generated `dist` folder via GitHub Pages or use a static hosting platform.
